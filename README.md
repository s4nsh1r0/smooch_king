# Smooch King 👑💋

An **idle dating sim** built with **Godot 4**.

Train stats, work jobs, meet characters around the city, and build relationships

---

## Features

- **City map & locations** — Home, Gym, Library, Cafeteria, Park, Mall, Nightclub, University, Cinema, Job Center
- **Idle training** — Start an activity at a location; gains continue offline with a reduced rate after 24 hours
- **Job shifts** — 4h / 8h / 12h shifts at the Job Center with pay and small stat bonuses
- **Action Points (AP)** — Passive AP over time; spend them on talk, dates, special tasks, and more
- **Relationships** — Stages from Stranger to Soulmate; talk, gifts, and dates
- **Shop & gifts** — Buy gifts at the Mall, give them through the gift button
- **Love Book** — Track characters you’ve met and your progress
- **Minigames**
  - Library — Crack the Code (4-digit pin)
  - University — Campus Word (Wordle-style, themed word list)
- **Save slots** — Two character slots from the title screen

## Running the project

1. Install [Godot 4](https://godotengine.org/download) (4.3+ recommended; project developed on 4.x stable).
2. Clone this repo:
   ```bash
   git clone https://github.com/s4nsh1r0/smooch_king.git
3. Open Godot → Import → select the project folder → Open.
4. Press F5 (or Play) to run.
